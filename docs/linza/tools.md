# Инструменты MCP

В обычной работе вам не нужно выбирать низкоуровневые инструменты вручную. Агент начинает с `agent_workspace` или `guide_next_steps`, а LINZA ведёт рабочий маршрут: проверить папку, проиндексировать, показать карту, собрать карточки проверки, обучиться на принятых примерах и предложить следующий шаг в предпросмотре.

## Основной набор

По умолчанию LINZA показывает компактный набор из 15 MCP-инструментов.

| Инструмент | Зачем |
| --- | --- |
| `agent_workspace` | Единый вход: проверка папки, карта, импорт, карточки, обучение, рост, связи, память и экспорт контекста |
| `guide_next_steps` | Показать следующий безопасный шаг понятным языком |
| `index_all` | Проиндексировать Markdown-папку в `.linza/linza.db` |
| `search` | Семантический и лексический поиск |
| `read_file` | Прочитать точный файл из рабочей папки |
| `get_stats` | Быстрые счетчики локальной базы |
| `scan_vault` | Диагностика папки без записи |
| `build_review_apply_queue` | Сформировать карточки проверки со стабильными `rq-*` ID |
| `approve_review_queue_items` | Пробный запуск или применение выбранных карточек |
| `list_approved_items` | Показать уже принятые локальные записи |
| `explain_node` | Объяснить один узел: ссылки, мосты, контекст |
| `explain_relationship` | Объяснить возможную связь между двумя узлами |
| `who_depends` | Показать зависимости и соседей |
| `show_flow` | Найти маршрут или поток между узлами |
| `create_context_pack` | Собрать компактный пакет контекста для агента |

## `agent_workspace`

Это основной вход для агента. Внутри него доступны рабочие действия вроде `doctor`, `map`, `review`, `teach`, `grow` и `connect`. Вы видите короткий статус, доказательства, следующие шаги и понятное объяснение, что может измениться; сырой JSON остаётся техническим слоем.

## Проверка и применение

LINZA использует стабильные `rq-*` ID. Это нужно, чтобы применение было точным: принять можно только конкретные карточки, которые вы видели. Если ID не совпадают, лучше остановиться и пересобрать предпросмотр.

## Расширенный набор

Для разработки и отладки можно включить расширенные инструменты:

```powershell
$env:LINZA_TOOL_SURFACE="advanced"
```

В обычной пользовательской работе это не требуется. Основной путь лучше оставлять коротким: диагностика, индекс, карта, карточки проверки, обучение и следующий предпросмотр.
