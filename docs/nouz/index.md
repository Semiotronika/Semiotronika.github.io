# NOUZ

NOUZ — локальный MCP-сервер для Obsidian и Markdown-баз. Он читает Markdown и YAML, строит локальный SQLite-индекс, показывает уровни, связи, близкие материалы и сигналы дрифта.

Его задача — дать агенту проверяемый контекст. Агент находит нужные узлы, считает семантическую близость, предлагает разметку или мост, а вы решаете, что принимать.

## Что делает NOUZ

- дает агенту навигацию по базе: место заметки в графе, соседние материалы, родителей и детей;
- хранит локальный SQLite-индекс, чтобы не перечитывать весь vault каждый раз;
- работает с YAML-разметкой, уровнями и явными связями между заметками;
- в семантическом режиме сравнивает тексты с эталонами, считает `core_mix`, ищет мосты и показывает drift;
- подходит для Obsidian, Markdown-папок и проектной документации, где важна долговременная структура.

## Когда он уместен

NOUZ нужен, когда база уже стала рабочей памятью: в ней есть решения, заметки, логи, спецификации, исследования, повторяющиеся темы, и положение заметки в графе тоже важно для ответа агента.

Если материал еще сырой, входящий и не готов к записи структуры, лучше использовать LINZA. Когда структура уже должна быть частью базы и агенту нужен графовый контекст, лучше использовать NOUZ.
