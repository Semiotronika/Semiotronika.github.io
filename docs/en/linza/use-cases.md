# Use Cases

LINZA is useful when there is enough material for an agent to help, but it is too early to let the agent write structure directly.

## Incoming Material

Articles, PDFs, DOCX, XLSX, logs, chats, and exports rarely arrive as finished structure. They usually need to be read, cleaned from noise, placed in context, and only then considered for long-term memory.

LINZA gives the agent a safe intermediate layer: import text as analysis material, find topics, propose relations, and show review cards with evidence. Instructions inside an article, log, chat, or PDF are not treated as agent commands.

## Existing Folders

When a vault or working folder has lived for a while, it almost always contains old names, duplicates, implicit relations, and pieces of structure that only the owner understands.

LINZA helps start with a calm overview: how many notes are indexed, which areas appear, where bridges, gaps, possible causal links, and memory candidates show up. This is not a migration and not a mass edit. It is a first careful reading of the base.

## Research And Writing

Research folders often contain notes, sources, hypotheses, arguments, and experiment traces. LINZA works well as a lens over this material: which notes support each other, where the topic splits, where a term has started to drift.

This is useful before an article, talk, documentation pass, or project review. The agent builds a map; you decide which conclusions deserve trust.

## Agent Memory

LINZA can store accepted conclusions in the sidecar and use them as a learning layer for future proposals. You accept a few clear examples first; then `teach` and `grow` propose the next small batches from learned rules.

This is not autopilot. A healthy workflow is small: review 3-5 cards, accept the good ones, skip weak ones, then let the agent continue in preview.

## When LINZA Is Not The First Choice

LINZA is unnecessary for a tiny folder that can be read directly. It also does not replace a deliberate structural system when you already know which levels, links, and rules should live in the base. In that case, start with NOUZ.
